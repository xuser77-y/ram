# Atlas Air — Airline Booking Homepage Demo

A front-end demo of an airline booking homepage, built with React + Vite.
It recreates the *structure* of a typical airline site — hero, flight search,
destinations, offers and loyalty section — with original code, original copy
and locally generated pictures.

**Demo only — not affiliated with any real airline.** All flights, prices and
booking/check-in/status results are mock data. There is no real checkout or
backend.

## What's in it

- Hero + flight search widget with 3 tabs: Booking, Manage & Check-in, Flight Status
- Destination cards with generated pictures: Paris, London, New York, Cairo,
  São Paulo, Istanbul — with MAD round-trip prices
- Offers, perks (meals, free luggage, entertainment, legroom), Safar Flyer
  loyalty section, newsletter, footer
- Working mock search: Casablanca plus Marrakech, Agadir, Tangier, Fes and
  Dakhla, plus the 6 international cities above
- "Book now" prefills the search; check-in and flight status return mock results

## Run it

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Stack

React 19 + Vite. No backend, no real booking.
